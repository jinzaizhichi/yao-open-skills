# 第七张缴费单

父亲住院第十九天，收费窗口打出第七张缴费单，三千八百七十一块六毛。

我把钱转给姐姐。

她回了两个字：收到。

父亲每晚一点二十分换冰袋。姐姐一共换了五十八次。这个数字不在缴费单上，是护士交班时告诉我的。

姐姐问过一次，你能不能替我一晚。

我说，明早有会。

她说知道了。

出院那天，窗口退了四十七块三毛。工作人员问退回哪张卡。

我说原路。

他说，原来的卡有七张。

我低头一张一张认。七张都是我的。

护士把父亲推出来时，他先叫了姐姐的名字。

姐姐正在办护理床退租。十九个晚上，一晚二十八块。她没让我报。

我把七张缴费单折好，放进父亲的药袋。

回家以后，药袋每天打开四次。

缴费单一次也没有再拿出来。
